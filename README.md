## App Loading Screen

On each launch, it will randomly pick an available port to launch our graalvm-compiled spring boot backend. 

This desktop application has two backends:

- the Rust-native backend by Tauri for OS-level API, and
- the GraalVM complied backend of Spring Boot for App Level API
